# tsubuyaki

電話占いウィルのサイトにある「つぶやき」欄に、待機が始まる前に投稿する文を作ります。書き手は鑑定師・汐見カノア（しおみ かのあ）です。

作る前に必ず次の2つを読みます。

- `reference/profile.md`：先生のプロフィール、得意分野、口調のルール
- `reference/posts.md`：これまでの投稿履歴と、参考にしている売れっ子の先生のつぶやき

## 1. ユーザーに確認すること

足りなければ聞きます。ただし、なくても作り始めてかまいません。

- 待機時間：分からなければ「〇時」と空欄にして、完成版は後で埋める
- 入れたい話題：その日の出来事、季節のこと、キャンペーンなど。「特になし」でもよい

## 2. 文の組み立て

1. **最初に、読む人の気持ちに触れる一言を置く**：お悩みの心の声（「あの人は今、何を考えているんだろう」など）や、問いかけ、季節の話題から始める。「お知らせ」から書き始めない。
2. **先生だからできることを1つだけ入れる**：思い込みやマインドブロックを外す、お相手の本音を読み解く、オーラやエネルギーからのメッセージ、遠隔ヒーリング、浄化した鑑定部屋など。毎回全部は入れない。
3. **最後に待機の案内を入れる**：「本日は〇時より待機しております」「お待ちしておりますね♡」など。

## 3. 守ること

- **140字以内**。改行も含めて数え、各案の字数を確認する。
- 口調は `reference/profile.md` の「口調のルール」に合わせる。
- `reference/posts.md` の直近の投稿と、話題や言い回しが重ならないようにする。同じ日に2回投稿する場合は特に注意する。
- 「必ず叶う」「絶対に復縁できる」など、結果を約束する言い方はしない。
- 先生の体験や出来事を勝手に作らない。日常の話題は、ユーザーから聞いたものだけを使う。

## 4. 出し方

- 切り口の違う案を3つ出す（例：心の思い込み／恋愛・お相手の気持ち／季節や日常）。
- それぞれに短い見出しをつけ、本文はコードブロックに入れてそのままコピーできるようにする。
- 最後に、待機時間の空欄や調整（もっとくだけた口調にする、短くするなど）に対応できることを一言添える。

## 5. 投稿後に記録すること

ユーザーが「〇案で投稿した」と教えてくれたら、その本文を `reference/posts.md` の「これまでの投稿」の一番上に日付と時刻つきで追加し、コミットしてプッシュする。時刻が分からなければ日付だけでよい。
