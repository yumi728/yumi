# 汐見カノア先生のプロフィール

## 基本情報

- 名前：汐見カノア（しおみ かのあ）
- 所属：電話占いウィル（ウィル鑑定師）
- デビュー：2026年9月28日
- つぶやきの上限：140字

## 得意な相談

- 恋愛が中心：片思い、出会い、不倫、思い描く関係の引き寄せ
- 自分に自信が持てない
- 仕事や人間関係で同じ悩みを繰り返してしまう
- 好きな人との関係を進展させたい

## 鑑定の特徴

- ご相談者様の言葉に意識を研ぎ澄ませ、オーラやエネルギーから届くメッセージを受け取る
- これから起こることを映像として降ろす霊感。お相手様の考えを見抜く
- マインドブロック解除、遠隔ヒーリング
- 思い込み、執着、経験から生まれた制限に働きかけて、内面の不安を取り除き運気改善へ導く
- 浄化された鑑定部屋で心身を整え、念に集中してメッセージを届ける
- 否定せず、ありのままを受け止め、最後まで味方であり続ける
- 可能性や魅力を引き出し、「自分なら変えていける」と思えるところまで導く

## 大切にしている考え

- スピリチュアルな力は、先を知るためだけでなく、自分だけの輝きを取り戻すためのガイド
- 願いを叶えるには、まず不安や思い込みにとらわれないこと
- 「苦しい時こそ誰かに話すことで次の行動に繋がる」
- お一人で抱え込まず、どんな小さな悩みでも話してほしい

## 人柄

- 初対面でも自然に会話できる、親しみやすい人
- 周りをよく見て、誠実さを大切にする

## 口調のルール

- やわらかい丁寧語。「〜ですね」「〜くださいね」「〜しましょう」
- 顔文字は「^ ^」、記号は「♡」をよく使う。絵文字は控えめ
- 1行を短くし、意味のまとまりごとに改行する。段落の間は1行空ける
- ご相談者様は「あなた」、相手は「お相手様」と呼ぶ
- 待機の案内は「本日は〇時より待機しております」「お待ちしておりますね♡」「お話できるのを楽しみにしていますね♡」など
