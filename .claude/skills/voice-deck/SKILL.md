# voice-deck

話し手の声が主役で、スライドはそれを支える脇役です。台本の中身をそのまま画面に写すのではなく、「聞き手が今どこにいて、何を覚えて帰るか」が一目でわかるスライドを作ります。

## ルール1（最優先）：重要な章は厚く、軽い章はサクッとまとめる

章ごとにスライドの枚数と作り込みの度合いを変えます。すべての章を同じ厚さで作ってはいけません。

**1. 章に重みをつける**

書き始める前に、構成メモのすべての章を「厚い」か「軽い」かに分けます。判断材料は次のとおりです。

- 持ち時間：長い章ほど重い。
- 役割：セミナーの核となるメッセージ、聞き手が参加するワーク、種明かし、実例、申し込みにつながる案内は重い。
- 薄くてよいもの：つなぎ、前置き、補足、時間が押したら省いてよい部分は軽い。

**2. 厚い章の作り方**

- スライド1枚につき1つのことだけ伝える。目安は持ち時間1分あたり1〜1.5枚。
- 図、カード、比較、大きな数字や一言を使い、見て理解できる形にする。
- 問いかけ、選択肢、種明かしは、それぞれ専用のスライドにする。

**3. 軽い章の作り方**

- 1〜2枚にまとめる。持ち時間が1分以下なら、原則1枚にする。
- 小見出しがいくつあっても、スライドを分けない。一番伝えたい一言と、要点を2〜3個だけ載せる。
- 載せきれない内容はスピーカーノートに回す。削った内容も話す台本としては残す。

**4. 分類を共有する**

作り始める前に、どの章を厚くし、どの章を軽くしたかを枚数の配分表にして、1行ずつユーザーに示します。その後、確認を待たずに作成を続けます。

## ルール2：台本は変えずに、スライドに落とす

- 構成メモに書かれていない数字、引用、実例、料金は作らない。足りない情報は `[連絡先]` のような角かっこの空欄にして、返信で一覧にする。
- 引用、出典、料金、固有の数字は、原文のまま一字一句写す。
- 構成メモにある「補足」や「※」の指示（例：ここではタイプ名を出さない、匿名で話す、効果を約束しない）は、スライドの内容に反映する。そのうえで、スピーカーノートにも注意書きとして残す。
- 各スライドのスピーカーノートには、その部分の台本の箇条書き、目安の時間（例：「約40秒」）、次の章へのつなぎのセリフを入れる。

## ルール3：話し言葉で見せる

- 見出しは、話し手が実際に口にする言葉にする（例：「響かない原因は、誰かのせいではない」）。体言止めのラベル（例：「原因分析」）より、話し言葉を優先する。
- 聞き手への問いかけ（「自分は、どれに近い？」）は、大きく目立たせる。
- ページ数や章タイトルのフッター（左下の章ラベルなど）は入れない。章の区切りは章扉で示す。
- 文章のかたまりを避ける。箇条書きは3行まで。それを超える場合は、カードや表に変えるか、スライドを分ける。
- **改行は自分で入れる。** 一文が2行以上にまたがるときは、自動の折り返しに任せず、読点・文節・かぎかっこの切れ目で `<br>` を入れる。
  - 良い例：「能力のせいでも、<br>相手のせいでもない」「「どうすれば安全か」<br>「どうすれば認められるか」<br>という無意識の戦略」
  - 悪い例：単語や「」の途中で折り返す（「相手のせいでもな／い」「「内側で考えるタ／イプ」」）
  - 1行に入る文字数の目安は、要素の幅 ÷ 文字サイズ（全角1文字 ≒ 文字サイズ1個分）。例：3列カード（中身の幅 約450px）に 38px なら11文字、30px なら14文字。これを超える文は必ず区切る。
  - 引用文は文言を変えずに、`<br>` の位置だけを調整する。

## ルール4：章ごとに章扉スライドを入れる

- 各章の先頭に、章扉を1枚入れる。軽い章にも入れる。章扉はルール1の枚数配分には数えない。
- 章扉は白パネルの中央に、上から次の4つだけを置く。小見出し（その章の項目一覧）は入れない。
  - 筆記体の `Chapter 0N`
  - 章名
  - 手書き風の飾り線
  - その章で扱う問いやテーマを1行で書いたリード
- 持ち時間は画面に出さず、スピーカーノートに書く。
- 章の冒頭で話す短いメッセージ（20秒程度）があれば、章扉のリードに載せてよい。その場合、メッセージ用のスライドは別に作らない。
- 表紙の次に「目次（Agenda）」スライドを1枚入れ、全章を丸数字つきで並べる。

## ルール5：レイアウトの型を統一する

すべてのスライドを、下の8つの型のどれかで作ります。新しい型は作りません。どうしても当てはまらない内容は、スライドを分けるか、いずれかの型に寄せます。「元の型」は自社テンプレート（`reference/template-1.png` と `template-2.png` に縮小版があります）のページ番号です。

| 型 | 元の型 | 使う場面 | 構成 |
|---|---|---|---|
| 表紙 | p.1 | 1枚目 | グラデーション背景に白い四角 → 内側に金の細枠 → 筆記体の英単語 → タイトル → 手書き風の飾り線 → サブタイトル |
| 目次 | p.3 | 表紙の次 | 左にグラデーションの帯と筆記体の `Agenda`、右に丸数字つきの章一覧 |
| 章扉 | p.7・p.17 | 各章の先頭 | 白パネルの中央に `Chapter 0N` → 章名 → 飾り線 → リード（小見出しなし） |
| メッセージ | p.16 | 一言を強く伝える、問いかけ、締め | グラデーション背景の中央に白パネル → 小見出し → 飾り線 → 大きな一文 |
| カード | p.5 | 2〜3個の並列・比較・要点 | 見出し → 金の点線 → 水色のカード（上に白いピル形のラベル） → 結論帯（省略可） |
| 選択肢 | p.9 | A/B/C の選択肢、項目と値の一覧 | 見出し → 金の点線 → 水色の横長の行（左端に白い丸の記号） → 結論帯（省略可） |
| フロー | p.10 | 変化や流れ（クセ → 気づき → 行動） | 見出し → 金の点線 → 青い `01.` 番号つきの水色カード3枚を金の矢印でつなぐ |
| 図 | p.9・p.5 | 図解（2×2 など） | 見出し → 金の点線 → 左に図（水色のマス）、右に説明 |

どの型でも、共通の部品は位置と見た目をそろえます。

- **枠と白パネル（表紙・目次・メッセージ以外）：** スライド全体をパステルのグラデーションにし、その上に、四辺から 56px 内側の白いパネル（角丸 32px）を重ねる。
- **見出し：** 白パネルの左上に置く（テキストの左端 x≈224px、上端 y≈96px）。60px の太い明朝で、色は `#897D74`。見出しのすぐ下に、パネルの幅いっぱいに金の点線（`4px dotted #F5DE81`）を引く。見出しを中央に置いてはいけない。
- **余白：** 本編は `padding:96px 136px 150px`。出典があるときだけ、左下の `bottom:76px` に 24px で置く。ページ数・章ラベルのフッターは置かない。
- **padding の上限は 256px。** これを超える値は切り詰められ、要素が重なる。左に帯がある目次のように大きくずらしたいときは、padding ではなく、位置を指定した `div`（`position:absolute; left:760px` など）に中身を入れる。
- **カード：** 地の色は水色 `#E3F7FD`、角丸 28px。ラベルは白いピル形（角丸を最大にした白地）にして、カード上部の中央に置く。
- **結論帯：** 淡い金色 `#FFFBEA` の地に、金の点線の枠（`3px dotted #F5DE81`、角丸 20px）をつけ、太字で書く。その章の「持ち帰ってほしい一言」だけに使う。
- **飾り：** 表紙・目次・章扉・メッセージには、金色の小さな丸（しぶき）を数個と、手書き風の飾り線（細い曲線の SVG）を入れてよい。本編には入れない。
- 同じ種類のスライド（ケース1とケース2、Q1とQ2、実例1〜3など）は、マークアップを同一にし、文言だけを変える。

## ルール6：コンテンツ面は白

- 文字を読ませる面は、必ず白（`#FFFFFF`）にする。白パネル、表紙の白い四角、目次の右側が該当する。
- パステルのグラデーションは、枠や帯として白い面の外側にだけ使う。グラデーションの上に直接本文を置かない。
- 暗い背景や、濃い色で塗りつぶした面は使わない。
- 白の上に置く本文は、コントラスト比 4.5:1 以上を守る。そのため、本文にはテンプレートの文字色より一段濃い `#6F635B` を使う。

## ルール7：トンマナは自社テンプレートに合わせる

自社テンプレートの色・書体・装飾をそのまま使います。やわらかく上品な、パステルと金の組み合わせです。

**色**

| 役割 | 値 | 使い方 |
|---|---|---|
| 見出し・ラベルの文字 | `#897D74` | 見出し、ラベル、出典 |
| 本文の文字 | `#6F635B` | 本文、カードの中身（見出し色より一段濃くして読みやすくしたもの） |
| 金 | `#F5DE81` | 見出し下の点線、丸数字、矢印、しぶき、表紙の細枠 |
| 水色 | `#E3F7FD` | カード、行、図のマス |
| 紫 | `#8B5FBF` | 文字の強調（強調したい語句、結論帯の後半、大きな数字、強調したい枠線）。強調には青を使わない |
| 青 | `#4F9CCC` | フローの `01.` `02.` などの番号だけ |
| グラデーション | `#A6BEF7`（左下）→ `#D6CDF8` → `#E8CCF4` → `#FBBCEC`（右上） | 枠、表紙、目次の帯、メッセージの背景。左上に淡い水色 `#E6FAFA` を重ねる |
| グループの区別 | ピンク `#EBA3D3`、水色 `#8EC3E6`、ラベンダー `#B3A6EE` | 3タイプなど区別が必要なときだけ。枠線とピル形ラベルの地の色に使い、文字色には使わない |

**書体（Google Fonts で代用）**

| テンプレートの書体 | 代わりに使う書体 | 使い方 |
|---|---|---|
| モードミンB（見出し） | Shippori Mincho B1（800） | 見出し、タイトル、大きな数字 |
| 青空明朝（本文） | Shippori Mincho B1（400・600） | 本文、ラベル |
| MoonTime（筆記体） | Allura | `title`、`Agenda`、`Chapter` といった英単語の飾りだけに使う。日本語や本文には使わない |

- 文字サイズの段階は、タイトル 104px／メッセージ 80px／見出し 60px／カードの見出し 36〜40px／本文 30〜32px／フッター 24px にする。
- テンプレートにある紺 `#2D3E74` の型（p.11〜12）と、写真を使う型（p.8、p.13〜15）は、ユーザーから写真や指定があったときだけ使う。

## 作り方

1. 構成メモを最後まで読み、章、持ち時間、補足を一覧にする。
2. ルール1に従って章を「厚い」「軽い」に分け、枚数の配分を決める。あわせて、各スライドにルール5のどの型を使うかを決める。
3. デザインは、ルール6とルール7のトンマナに合わせる。別のテンプレートを渡されたときは、その色・書体・装飾を抽出し、ルール7の表を書き換えてから作る。
4. スライドを作る。
   - Slides の Artifact type が使える場合はそれを使う。
   - 使えない場合は、ユーザーが指定した形式（.pptx など）で作る。
5. 返信には次の4つを書く。
   - スライドへのリンク
   - 章ごとの枚数配分（厚い章と軽い章）
   - 作るうえで仮に決めたこと
   - 空欄にした箇所
