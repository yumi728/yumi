# voice-deck

話し手の声が主役で、スライドはそれを支える脇役です。台本の中身をそのまま画面に写すのではなく、「聞き手が今どこにいて、何を覚えて帰るか」が一目でわかるスライドを作ります。

## ルール1（最優先）：重要な章は厚く、軽い章はサクッとまとめる

章ごとにスライドの枚数と作り込みの度合いを変えます。すべての章を同じ厚さで作ってはいけません。

**1. 章に重みをつける**

書き始める前に、構成メモのすべての章を「厚い」か「軽い」かに分けます。判断材料は次のとおりです。

- 持ち時間：長い章ほど重い。
- 役割：セミナーの核となるメッセージ、聞き手が参加するワーク、種明かし、実例、申し込みにつながる案内は重い。
- 薄くてよいもの：つなぎ、前置き、補足、時間が押したら省いてよい部分は軽い。

**2. 厚い章の作り方**

- スライド1枚につき1つのことだけ伝える。目安は持ち時間1分あたり1〜1.5枚。
- 図、カード、比較、大きな数字や一言を使い、見て理解できる形にする。
- 問いかけ、選択肢、種明かしは、それぞれ専用のスライドにする。

**3. 軽い章の作り方**

- 1〜2枚にまとめる。持ち時間が1分以下なら、原則1枚にする。
- 小見出しがいくつあっても、スライドを分けない。一番伝えたい一言と、要点を2〜3個だけ載せる。
- 載せきれない内容はスピーカーノートに回す。削った内容も話す台本としては残す。

**4. 分類を共有する**

作り始める前に、どの章を厚くし、どの章を軽くしたかを枚数の配分表にして、1行ずつユーザーに示します。その後、確認を待たずに作成を続けます。

## ルール2：台本は変えずに、スライドに落とす

- 構成メモに書かれていない数字、引用、実例、料金は作らない。足りない情報は `[連絡先]` のような角かっこの空欄にして、返信で一覧にする。
- 引用、出典、料金、固有の数字は、原文のまま一字一句写す。
- 構成メモにある「補足」や「※」の指示（例：ここではタイプ名を出さない、匿名で話す、効果を約束しない）は、スライドの内容に反映する。そのうえで、スピーカーノートにも注意書きとして残す。
- 各スライドのスピーカーノートには、その部分の台本の箇条書き、目安の時間（例：「約40秒」）、次の章へのつなぎのセリフを入れる。

## ルール3：話し言葉で見せる

- 見出しは、話し手が実際に口にする言葉にする（例：「響かない原因は、誰かのせいではない」）。体言止めのラベル（例：「原因分析」）より、話し言葉を優先する。
- 聞き手への問いかけ（「自分は、どれに近い？」）は、大きく目立たせる。
- 章の見出しの上に、小さく章番号と章名を入れる（例：`03　エニアグラムの位置づけ`）。聞き手が、話が今どこまで進んだかを見失わないようにするため。
- 文章のかたまりを避ける。箇条書きは3行まで。それを超える場合は、カードや表に変えるか、スライドを分ける。

## ルール4：章ごとに章扉スライドを入れる

- 各章の先頭に、章扉を1枚入れる。軽い章にも入れる。章扉はルール1の枚数配分には数えない。
- 章扉に載せるのは、次の3つだけにする。
  - 大きな章番号（`01`）
  - 章名
  - その章で扱う問いやテーマを1行で書いたリード
- 持ち時間は画面に出さず、スピーカーノートに書く。
- 章の冒頭で話す短いメッセージ（20秒程度）があれば、章扉のリードに載せてよい。その場合、メッセージ用のスライドは別に作らない。

## ルール5：レイアウトの型を統一する

すべてのスライドを、下の7つの型のどれかで作ります。新しい型は作りません。どうしても当てはまらない内容は、スライドを分けるか、いずれかの型に寄せます。

| 型 | 使う場面 | 構成 |
|---|---|---|
| 表紙 | 1枚目 | アクセントの短い線 → タイトル → サブタイトル → 一行説明 |
| 章扉 | 各章の先頭 | 左に大きな章番号、縦線をはさんで右に `CHAPTER 0N`・章名・リード |
| メッセージ | 一言を強く伝える、問いかけ | 見出し（見出し自体は省略可） → 大きな一文 → 補足の一行 |
| カード | 2〜3個の並列・比較・要点 | 見出し → 同じ幅のカード2〜3枚 → 結論帯（省略可） |
| 選択肢 | A/B/C の選択肢、項目と値の一覧 | 見出し → 横長の行を2〜4本 → 結論帯（省略可） |
| フロー | 変化や流れ（クセ → 気づき → 行動） | 見出し → リード（省略可） → 矢印でつないだ箱3つ → 結論帯（省略可） |
| 図 | 図解（2×2 など） | 見出し → 左に図、右に説明 |

どの型でも、共通の部品は位置と見た目をそろえます。

- **見出しブロック（表紙・章扉以外）：** 上の余白の位置に、章ラベル（24px、アクセント色）と見出し（64px、明朝）を置く。見出しを中央に置いてはいけない。
- **余白：** `padding:128px 128px 160px` で統一する。出典は下端 `bottom:64px` に、24px の一行で置く。
- **カード：** 薄い地の色で塗り、角丸 20px にする。中身は「ラベル → 本文」の順にする。
- **結論帯：** 左にアクセント色の太線を引き、淡いアクセント色の地に太字で書く。その章の「持ち帰ってほしい一言」だけに使う。
- 同じ種類のスライド（ケース1とケース2、Q1とQ2、実例1〜3など）は、マークアップを同一にし、文言だけを変える。

## ルール6：背景は白

- すべてのスライドの背景を白（`#FFFFFF`）にする。表紙、章扉、締めのスライドも同じ。暗い背景や、アクセント色で塗りつぶした背景は使わない。
- 色は、文字、線、カード・結論帯・番号といった小さな面で使う。
- アクセント色は1色にする。グループ分けなど、区別のための色が必要なときだけ、明るさの違う色を2〜3色まで足す。
- 白の上に置く文字は、コントラスト比 4.5:1 以上を守る。

## 作り方

1. 構成メモを最後まで読み、章、持ち時間、補足を一覧にする。
2. ルール1に従って章を「厚い」「軽い」に分け、枚数の配分を決める。あわせて、各スライドにルール5のどの型を使うかを決める。
3. デザインの方向（書体、配色）を1回だけ決める。
   - 日本語の場合は、見出しに明朝系、本文にゴシック系の Google Fonts を組み合わせる（例：Zen Old Mincho と Zen Kaku Gothic New）。
   - 背景は白にする（ルール6）。
4. スライドを作る。
   - Slides の Artifact type が使える場合はそれを使う。
   - 使えない場合は、ユーザーが指定した形式（.pptx など）で作る。
5. 返信には次の4つを書く。
   - スライドへのリンク
   - 章ごとの枚数配分（厚い章と軽い章）
   - 作るうえで仮に決めたこと
   - 空欄にした箇所
