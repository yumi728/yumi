# アカウント運用の方針

## 導線（まず目指すところ）

1. **プロフィールを整える**
   - 3連バナーを設置する
   - 3連バナーで「LINE に登録したら何がもらえるか」を具体的に示す
2. **入口ができたら、リールを数多く出す**
3. **すべてのリールに LINE 誘導を入れる**

LINE 誘導の回数が多く、精度が高いほど、LINE に見込み客がたまる。リールの本数が少ないと LINE に入る人も少なくなる。
→ 勝負は「**1週間の中で LINE 誘導の頻度と精度をどれだけ上げられるか**」。（2026-08-24）

## リサーチ対象の選び方

- 判断基準は**ターゲットの興味関心**（ライフスタイル、悩み、なりたい姿）。自分が言いたいことではない
- ターゲットが普段見ていそうなら、婚活・恋愛以外のアカウント（コミュニケーション系など）もリサーチ対象にしてよい
- 興味がなく流し見されそうなジャンルは対象にしなくてよい（2026-08-24）

## テーマのテスト

- 恋愛・結婚の話を中心にしつつ、仕事やコミュニケーション・人間関係の話を時々入れてみる
- 1本では判断しない。何本か出して総合的に判断する
- よく見られたら、そのテーマの割合を増やす（2026-08-24）

## リサーチから台本までの考え方

- リサーチで変わるのは**入口（扱うテーマ）だけ**。持っていき先（新常識・メソッド）は毎回同じ
- 毎回ゼロから新常識に繋ぐのではなく、一度深く掘った新常識を使い回す（→ [paradigm-shift.md](paradigm-shift.md)）（2026-08-24）

## 再生数の目標

1000回以上が出る頻度（勝率）を上げる → 3000の壁 → 5000の壁 → 1万の壁。（2026-09-21）

## リールから LINE までの期待をつなげる

プロフィールに来てくれても LINE に入らないのは、**リールで期待したことが、飛んだ先で待ち構えていない**から。
リール → プロフィール → 3連バナー → LINE 特典 の言葉と中身を、リールで受けているテーマに合わせる。（2026-09-21）

- 特典が、リールの内容（アラフォー婚活の実践的な話）とずれてスピリチュアル寄りに見えると、ギャップで離脱する
- リールでよく反応された言葉（「沼らせる」など）を、プロフィールや3連バナーでも使う
- 今ある特典は活かしつつ、「リールで受けているテーマで紹介するなら、どんな特典・どんな出し方になるか」を考える

## プロフィールの作り方

伸びているアカウントのプロフィールを分析した結果（2026-09-21、コンサルの方の分析）。

| 要素 | 型 | 例 |
|---|---|---|
| 肩書き | **対象＋テーマ＋役割** | 子供の口ぽかん卒業の専門家／小学校高学年の勉強習慣コーチ／大人の韓国語声出しコーチ |
| 1行目 | 一番ドキッとさせる一言。**新常識**をぶつける | 常識反転「子供の勉強はやる気より仕掛け」／痛み放置の損失「お口ぽかんの放置は歯並びに影響」／こだわり宣言「発音から、聞けて話せる土台をつくる」 |
| 手法 | そのまま書かず、**対比**で書く | 「〇〇しないで△△」「メイクで隠さず内側から」 |
| 手軽さ・期間 | 期間や手軽さを示す | 1日30分×半年／40代からでも／今日から |
| 実績 | 数字を入れる。**1行目より下**に置く（一番上に置いている人はいない） | 相談2000件以上／累計1万人以上 |
| CTA | 何がもらえるか | |

- 肩書きを見て、**誰に何をしてくれる人か**が一瞬で分かること
- 1行目を見て「これは知らなかった。だからこういう発信をしているのか」と思えると、フォローされる
- ターゲットを混ぜない。**出会う前／結婚／関係改善**が混ざると、「私のことだ」と思う前に迷う
- 抽象的な言葉（「しなやか」など）は、何がどうなるのかが見えないので避ける

## 3連バナー

- 基本構成：真ん中に人物、誰に向けて何を言うかを大きなコピーに、その内訳を下に（2026-09-21 時点で構成は OK）
- コピーは**誰がどうなるための企画か**が分かる言葉にする。相手目線の言葉選び（2026-09-21）

## リールの中での LINE 誘導

見本：門口さんの「設定10個」のリール（2026-09-21）

- 誘導は最後だけでなく**途中にも**入れる。ただし回数が大事なのではない
- 大事なのは**どうしたら特典が欲しくなるか**。リールのテーマにぴったりの特典を、**なぜ必要か**と一緒に紹介する
- 情報を一気に出して「ついていけない」と感じさせてから、「全部ここにまとめてあるから大丈夫」と渡す
- 具体例（ジャンル別の例文など）を見せた直後に、「全パターンまとめてある」ともう一度渡す
- **もらえるものを目で見せる**：診断画面のスクショ、マニュアルの画像、ボリューム、「3分でできる」などの手軽さ
- ユミさんの場合：ジャンル別 → **タイプ別**に置き換えられる。「あなたが何タイプで、そのタイプならどう言えばいいか、ここに全部まとめている」
- 普段から、門口さんや杉さんのリールを「いつ、どんな文脈で、どう LINE 誘導しているか」という目で見る

## LINE 登録から個別相談まで

（2026-09-21 の改善提案）

1. 個別相談の案内で、**カルーセルのボタンを押すだけ**で申し込めるようにする（フォーム入力やカレンダー選択はやめる）
2. 押したら自動応答：「平日の日中／平日の夜／休日の日中／休日の夜、どれがいいですか？」
3. 回答に合わせて「直近だと〇日の夜はどうですか？」とやり取りして日程を決める
4. 決まったら、当日までに今の状況をヒアリングし始める。ユミさんの過去の話や、タイプを知らなかったせいでうまくいかなかった事例を出して、タイプを知る大切さを意識してもらう
5. 当日は「初めましてだけど初めましてじゃない」状態で話せるので、成約率が上がる

- 申し込みのハードルを下げて、相談に来る人を増やすことが先。人数が増えたらカレンダー予約に戻してもよい
- 個別相談の流れ：あなたは何タイプで、彼は何タイプで、どうするべきかを作戦として話す → タイプを意識して接するのを癖にするには数ヶ月かかる → 講座へ
- LINE 登録後の挨拶文、特典の渡し方も見直す
