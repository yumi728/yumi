# フックの型（門口式・冒頭4分類）

出典：コンサルの方が作成した「門口さんリール分解」（Google ドキュメント ID: `1e3tFRU4CdGUlo40IhqtUKnt2d6CFizSVGJ23Y70Oh8A`）。門口さんの台本411本とトークリール完全攻略マニュアルから抽出したもの。ここでは要点だけをまとめる。台本番号や実例の全文は元資料を参照。

## 4つの切り口

| 切り口 | 定義 | なぜ効くか |
|---|---|---|
| 常識破壊 | 視聴者が信じている「常識」「普通」を覆す | 新しい情報・真実を知りたくなる |
| ネガティブ訴求 | ある事象にマイナスを持たせて訴求する | 避けたい未来・問題点が気になる |
| 短期的快楽 | すぐ効果が出る／すぐ実践できると示す | 少ない手間で大きな結果を期待する |
| 感情爆発 | 喜怒哀楽をタイトルに含める | 何が起きたのか知りたくなる |

**門口さんのフックは9割が2つ以上の掛け合わせ。** 単独より組み合わせを狙う。

## 切り口ごとの型

### 常識破壊
- 成果否定：「〇〇しても無意味です」
- 推奨行為の否定：「〇〇はもう不要です」
- 信じてる人＝情弱：「〇〇が大事って思ってる人、情弱です」
- オワコン宣言：「〇〇はもうオワコンです。は？？？？」
- 期待を先に潰す：「〇〇の裏技！結論、そんなもんありません」
- A じゃなくて B：「〇〇が大事と言われてますが違います、△△です」

### ネガティブ訴求
- NG行動〇選：「〇〇が下がる絶対NG行動〇選」
- 該当者終了宣告：「〇〇な人は終わりです」
- できない人の特徴：「絶対に〇〇されない人の特徴」
- 知らずにやってる系：「知らずにやってるとどんどん〇〇します」
- 注意喚起・告発：「注意喚起です」「あれ全部嘘です」
- 最悪の未来提示：「このままいくと〇〇になります」
- 反転ネガ（上級）：「絶対に〇〇したくない人がやるべき行動〇選」

### 短期的快楽
- 一撃系：「一撃で〇〇する裏技」
- 数字×期間：「1ヶ月で〇〇」
- 倍率提示：「〇倍になる」
- 〜するだけで：「〇〇するだけで△△になります」
- 〇選・保存版：「完全保存版〇選」
- 選ばれし者演出：「この動画が表示された人は〇〇」
- まだ誰も言ってない：「9割が知らない〇〇」

**門口さん独自の使い方**：短期的快楽の直後に「んなわけないやろ！って思った人ほど勘違いしてることがあって」と自分でツッコみ、釣りっぽさを消して常識破壊に橋渡しする。

### 感情爆発
怒（視聴者へ／第三者へ）、ツッコミ、謝罪型「大変申し訳ございませんでした」、緊急型「今緊急で動画回してるんですけど」、暴露・覚悟型「これ言うと敵が増えるので怖いんですが」、ボケ・不意打ち、哀・弱さの開示「心折れそうです…」

注意：怒と哀は伸びやすいが、使いすぎるとうざがられる。たまに出すくらいがちょうどいい。

## 定番の組み合わせ

| 組み合わせ | 構造 |
|---|---|
| 常識破壊 × ネガティブ | 常識を壊す → 放置した最悪の未来 |
| 短期的快楽 × 常識破壊 | 期待を煽る → 自分でツッコむ → 常識破壊 |
| 感情爆発 × ネガティブ | 怒り → 原因の指摘 |
| 感情爆発 × 常識破壊 | 極論 → 自分で全否定 |
| 謝罪 × 常識破壊 | 過去の自分の主張を撤回する形 |
| 短期的快楽 × 選ばれし者 | 特別感 → 数字 |

## フック直後に入れるもの（冒頭5〜8秒）

1. 冒頭フック（4切り口のどれか、または掛け合わせ）
2. ターゲティングコール（「〇〇な人は」と対象を名指し）
3. コールドリーディング（視聴者の心情・行動を代弁）
4. 最悪の未来、または解決策への期待
5. 本編へ

## 穴埋めテンプレ（1つのテーマから必ず4パターン出す）

- テーマ：
- 対象者がやっている行動：（[paradigm-shift.md](paradigm-shift.md) の行動層から）
- 対象者が信じている常識：（同じく定義層から）

1. 常識破壊：「（信じている常識）は実は逆で、〇〇です」
2. ネガティブ：「（その行動）を放置すると△△になります」
3. 短期的快楽：「（悩み）は〇〇するだけで一撃で解決します」
4. 感情爆発：「（業界の嘘・間違い）に、むちゃくちゃ腹が立ってます」

お手本（M さん／食いしばり）：常識破壊「食いしばりはほぐせば逆に定着します」／ネガティブ「食いしばりを放置すると1年で10歳老けます」／短期的快楽「長年の食いしばり癖は舌の運動で一撃でなくなります」

門口さんの指導：「冒頭は**対象者の手を止めることに振り切って**考える」

## チェックリスト

- [ ] 4切り口のどれかに明確に当てはまるか（当てはまらない＝ただの説明）
- [ ] 濁していないか（「これやるとダメです」→ 何がダメか具体的に）
- [ ] 想定内の結論を先に言っていないか（「でしょうね」で終わる）
- [ ] 逆に、結論が見えなさすぎないか（「は？」で終わる）
- [ ] 誰に向けた話か、0.8秒で分かるか（ターゲティングコール）
- [ ] フック直後に心情・行動の代弁があるか
- [ ] 感情爆発を連発していないか
- [ ] フックから興味づけまでが5〜8秒に収まっているか

## 強ワード

- 常識破壊寄り：完全にオワコン／衝撃の事実／暴きます／暴露します
- ネガティブ寄り：絶対NG／終わりです／損します／絶対禁止／絶対にやっちゃダメ
- 短期的快楽寄り：一撃で／裏技／〜するだけで／たった〇〇で／完全保存版／99%は知らない／爆発的に／最新の
- 感情爆発寄り：大変申し訳ございません／今緊急で動画回してます／悪用厳禁
