# 新常識（パラダイムシフト）の掘り方

2026-08-24 のコンサルで、「パラダイムシフト作成ワークシート」に沿って実際に掘った内容。

## なぜ台本に時間がかかっていたか

- 今の新常識「自分の潜在意識タイプを知るといい」は**抽象度が高い**
- だから新しいテーマを拾うたびに「このテーマとタイプの話をどう繋ごう」とゼロから考え直していた
- 書き方の問題ではなく、**掘った場所の問題**。一番深い「物語層（潜在意識・ブロック）」だけで語っているので、出てくる答えも抽象的になる

## 新常識の深さは5層

| 層 | 聞くこと |
|---|---|
| 行動 | 何をやっているか（動作） |
| 指標 | 何を見て、何を基準に次の行動を決めているか |
| 定義 | 何を正解だと思っているか |
| 原因 | うまくいかないのを何のせいにしているか |
| 物語 | どんな思い込みに縛られているか |

**いきなり中くらいの抽象度で考えると、中くらいのものしか出てこない。** 一度徹底的に具体まで降りてから、最後に1本にまとめる。

## ステップ

1. **掘る「行為」を1つ決める**
   - ジャンル（結婚）や領域（恋愛）では掘れない。行為まで下ろす
   - 「疲れる」などの**結果は外す**。結果が混ざると、行動を聞いたときに感情が出てきてしまう
   - **場面を1つに絞る**（例：気になる人と LINE しているとき／デート中／付き合い始めてから）。絞ると行動が一気に出る
2. **行動層を書き出す（一番大事）**
   - 実際のお客さんがやっていたことベースでよい
   - NG：「他人軸で生きている」「自己肯定感が低い」など、状態や頭の中の話
   - OK：「どこでもいいよと言って行き先を相手に決めさせる」など、**画面上で何が起きているか**
   - 引き出す質問：送信ボタンを押すまで何をしているか／送った後は何をしているか（既読から返信まで）／相手からボールが返ってきたら何と返しているか／日程調整ではどうしているか
3. **指標層**：その時何を気にして見ているか。何がOKなら送れて、何があると送れないか
4. **定義層**：何が正解だと思っているか。どうするのが正しいと信じているか
5. **原因層**（軽く流してよい）：うまくいかないのを何のせいにしているか
6. **物語層**（軽く流してよい）：その奥にある思い込み
7. **共通点**：行動と指標を上から全部読んで「何をしようとしている人の行動か」を一言にする
8. **旗印**：共通点を、キャッチーな一言にする
   - 「相手軸／自分軸」は業界で使い古されていて流される。**掘った具体から出た言葉**で立てる
   - 目の前の人にズバッと言うなら？「それって結局〇〇だよね」の形で言ってみる
9. **リールに落とす**：テーマが変わっても着地は同じ、を体感する（→ [reel-structure.md](reel-structure.md)）

> ユミさんの課題（コンサルの方の指摘）：「こう考えている」「こう思っている」は出てくるが、**それによって結局何をしてしまっているのか（動作）**まで落とすところが弱い。

---

## 掘った結果：LINE でデートの約束をするとき

### 1. 行為
気になる人と LINE でデートの約束をやり取りしているときに、相手に合わせてしまう

### 2. 行動（14個）
- ビクビクしながら文章を考える
- 相手の言葉に一喜一憂する
- 送信前に、これまでの会話履歴を全部見返す
- 不自然なところ、嫌な気持ちにさせる箇所がないか最終チェックする
- 語尾や言葉じりをつけたり消したりを繰り返す（入力しては消す）
- 一言一句、語尾をその都度調整する
- 重く思われないかを気にして文章を見返す
- 「追われる女になりなさい」「ガツガツ行くとモテない」などのノウハウに振り回される
- 何を書けばいいか分からず、1つの返信に時間をかける
- 送った後、何度も LINE を開いて送った文章を読み返し「ここが悪かったのかな」と反省する
- 自分の意見より先に、相手にどこがいいかを聞く
- 「〇〇か〇〇はどうですか？」と選択肢を出して相手の興味をうかがう
- 予定が合わないときは謝ってから別日を提案する（対応自体はできているが、申し訳なさが強い）
- 自分の予定は後回しにする

### 3. 指標（何を見ているか）
- 「無難」「これなら嫌われない」と思えたら送る（自信満々ではなく「大丈夫かな…」と思いながら押す）
- 自分の意見を載せず、相手に全部委ねる聞き方（「カフェと居酒屋どちらがいいですか」「昼と夜どちらが都合いいですか」）なら送れる
- 相手が言ったことと矛盾していないか
- 彼の立場で読んで、図々しくないか、押し付けがましくないか
- 踏み込みすぎていないか、自分の意見を言いすぎていないか
- 「相手が行きたくないならウザいかな」と相手の頭の中まで勝手に想像する
- 返信が来たら：日時まで決まったか
- 文末が「。」か絵文字か、話し言葉か敬語か（＝相手の温度感）
- 「やばい」と感じるとき：そっけない文面、「また確認してから連絡します」
- 返信の速さはあまり気にしない（自分も遅いので）。ただ1〜2日空くと凹む

### 4. 定義（何を正解だと思っているか）
- 相手に合わせて、嫌な気持ちにさせなければOK
- 自分の意見を言うと嫌われるので、我慢すればうまくいく
- 地雷を踏まないようにするのが正しい
- 正解がどこかにあって、それが分からないから不安
- **相手の気持ちが分かればうまくいく**
  - 占いの現場で「彼は今どう思ってると思いますか？」と何度も聞かれる
  - ユミさんの主張「相手の気持ちなんて分かりようがない」と真正面からぶつかる → **これが旧常識と新常識の対立軸**

### 5. 原因（何のせいにしているか）
いい人がいない／男運がない／いい人はもう売れている／自分の年齢（アラフォー）／自分の外見に自信がない、磨いていないから

### 6. 物語（思い込み）
自分には価値がない（無価値感）／自分は愛されない／自分は選ばれない側の人間／相手に嫌な思いをさせるとうまくいかなくなる

### 7. 共通点
**相手の気持ちを「正解」として当てに行っている。**
相手の気持ちを推し量ってばかりで、結局分からないのに、自分の頭の中で完結させようとしている。だからメンヘラになるし、こじらせるし、行動が重くなる。

- 相手の気持ちという、本来相手の中にしかない答えを、自分の頭の中だけで出そうとしている
- 絶対に当たらない → 当たらないからまた見返す、調整する、反省する、の無限ループ → 返信1つに何時間もかかる
- 本人の認識：「相手の気持ちが分かればうまくいく」「正解がどこかにある」
- 実際：分かりようがないものを、頭の中で当てようとしている

### 8. 旗印
- **あなたが話しているのは彼じゃなくて、頭の中で作った彼です**
- **相手のことを考えているようで、一番考えているのは自分のこと**（相手のこと考えてるようで自己中だよね）
- それは彼を思いやっているんじゃなくて、**嫌われたくないだけ**（自分が可愛いだけ／予防線を張っているだけ）
- 相手を見ていないのに、好かれるわけがない

### 9. 着地（やってほしい行動）
- 相手の好みを探ったり、語尾を変えたりするのではなく、**「ここに行きたい」と自分がしたいことを言う**
- 相手の頭の中は相手にしか分からない。**想像するのではなく聞く**
- 相手のご機嫌をうかがうのではなく、自分のやりたいことを伝える（自分軸に戻す）
- 彼の気持ちを当てに行くのはやめる → 先に知るべきは**自分がどのタイプか** → タイプ診断（公式LINE）へ
