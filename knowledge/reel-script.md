# リール台本づくりの引き継ぎメモ

以前の台本づくりチャットからの引き継ぎ内容（原文のまま保存）。

## 1. 発信者のプロフィール・サービス概要

- 発信者：ドレンテユミ（現実創造ライフコーチ）
- ターゲット：30〜40代の大人婚活女子。我慢して相手に合わせる「我慢する婚活」に疲れ、一人反省会や自爆を繰り返してしまう女性。
- サービスの核：「調和コミュニケーション」と「しなやか自分軸（自己受容）」。
- コア概念：
  - 旧常識：相手の顔色やLINEの文章から「正解」を当てに行こうとする（実は自分が傷つきたくないだけの「保身・予防線」）。対話しているのは実際の彼ではなく「頭の中の妄想の彼」。
  - 新常識：自分の心理タイプ（思考のクセや恐れ）を知り自分軸を取り戻す。相手の深層タイプ（男心）を理解し、我慢や媚びゼロで本音を対等に繋ぐ「調和コミュニケーション」を実践する。
- 最終目的：リール動画から公式LINE（「魂の潜在意識タイプ診断」）へ誘導すること。

## 2. 旗印（コアメッセージ・概念の定義）

- 旧常識（バッサリ切る部分）：
  - 相手の顔色やLINEの文章から「正解」を当てに行こうとするのは、思いやりではなく自分が傷つきたくないだけの「保身・予防線（正解の鎧）」。
  - 対話しているのは目の前の実際の彼ではなく、「自分の頭の中で勝手に作った『妄想の彼』」であり、ただの一人相撲。
- 新常識（導くゴール）：
  - 自分の心理タイプ（思考のクセや恐れ）を知り、自分軸（自己受容）を取り戻す。
  - 自然に相手の潜在意識が喜ぶ「調和コミュニケーション」を実践する。

## 3. 勝ちパターン・動画テーマ

- 伸びた実績：「沼らせる女が無意識にやっている会話テクニック3選」（視聴維持率・保存数が高かったため、横展開シリーズとして作成）。
- 引き継ぎ時点のテーマ：「沼らせる女が絶対にやらないこと（LINE編）」

## 4. 台本構成で絶対に気を付けること（ルール）

1. **抽象的な心理描写は一切禁止**
   - 「相手を優先して本音を隠す」等の綺麗な言葉は使わず、視聴者が「うわ、私これやってる…」と生々しく映像が浮かぶ【行動レベルの具体例】（スタンプ連打、タイマー返信など）で提示する。
2. **否定からの安心感と理由付け**
   - NG行動を突きつけて終わるのではなく、「でもね、あなたが悪いんじゃない。傷つかないための防衛本能（思考のクセ）が発動しているだけ」と救いを入れる。
3. **旗印への鮮やかな着地**
   - 表面のテクニックではなく、「妄想の彼との一人相撲をやめて自分軸（自己受容）を取り戻すこと」へパラダイムシフトさせる。
4. **強力なLINE誘導（コンサル指導）**
   - 動画終盤で必ず公式LINEの「潜在意識タイプ診断」へ繋げ、プロフィールのリンクをタップさせる明確なCTA（行動喚起）を入れる。
